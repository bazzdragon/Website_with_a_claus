# Website with a Claus

This Project was a school project where i had to vibe code a website with santa claus flying across the screen.

## Overview
Files for Website with a claus project.

## Tech stack
- HTML
- CSS

## Getting started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)

### Run locally
1. Clone the repo:
   ```bash
   git clone https://github.com/bazzdragon/Website_with_a_claus.git
   ```
2. Open `index.html` in your browser.

## Project structure
- `index.html` – main page
- `css/` – stylesheets
