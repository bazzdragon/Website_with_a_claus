# Website with a Claus

A simple website project.

## Overview
This repository contains the source for **Website with a Claus**. It’s intended as a small web project you can run locally and customize.

## Tech stack
- HTML
- CSS

## Getting started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)

### Run locally
1. Clone the repo:
   ```bash
   git clone https://github.com/bazzdragon/Website_with_a_claus.git
   ```
2. Open `index.html` in your browser.

## Project structure
- `index.html` – main page
- `css/` – stylesheets (if present)
- `assets/` – images and other static files (if present)
